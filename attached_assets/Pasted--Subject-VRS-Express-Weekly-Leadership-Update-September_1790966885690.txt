### Feature Improvements and Impact

**1. Admin visibility for NLA tickets ready for ordering — published**
- Added a green **“Ready for Order”** badge with a credit-card icon beside the existing NLA label in the admin ticket table.
- Uses the same readiness rules as the agent queue to identify researched tickets awaiting ordering.

**Expected impact:** Helps admins distinguish actionable P-card ordering work from tickets still requiring research, without changing assignment permissions or the ordering workflow.

**2. Sasha photo support in production — published**
- Removed the development-only restriction on bridge-photo support and added the production Sasha photo host to the approved source list.
- Preserved ticket-access checks for retrieving photos.

**Expected impact:** Enables reviewers to access supporting photos supplied through Sasha, addressing the gap where image references were stored but not displayed in production. This reduces the need to seek evidence outside the ticket; the reduction in review effort has not yet been measured.

**3. Production VRS AI connection configuration — published**
- Added the production AI service address and Express callback origin to the production configuration.

**Expected impact:** Addresses the missing destination/callback configuration that blocked outbound AI handoff. Publication of these settings does **not** by itself confirm successful end-to-end authorization; credential compatibility and callback completion still require verification.

**4. Five-minute admin queue alerts — completed in development; not yet published**
- Added flashing red rows and a **“Waiting 5+ minutes”** indicator for actively queued tickets.
- Added one-second timer updates and notification sounds using existing tone and volume settings, including mute.
- Preserved business-hours timing and excluded claimed/completed tickets and researched NLA tickets with frozen handoff timers.

**Expected impact:** Gives admins earlier visibility into unattended queue work. Development checks passed, including browser verification of the five-minute transition. Production impact will be assessed after publication.
