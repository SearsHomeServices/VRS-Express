---
name: Ticket agent search scope
description: User-required reviewer coverage and date-window behavior for ticket searches.
---
Searching an agent name must include tickets they reviewed across outcomes, including rejected, invalid, and approved, within the selected timeframe.

**Why:** The user found that rejection clears assignment and therefore hid rejected work from agent-name searches.

**How to apply:** Do not treat current assignment as the only evidence of who worked a ticket. Preserve reviewer attribution without changing ticket ownership. Search should honor the existing created-date range; use All time explicitly for older records. Keep table and coaching-export matching consistent.
